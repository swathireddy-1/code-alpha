# Phishing Awareness Training

A small Python command-line training module that teaches users to identify
phishing emails, fake websites, and social engineering.

## Project files

```text
phishing_awareness_training/
├── phishing_training.py
├── training.txt
└── README.md
```

## Requirements

- Python 3.8 or newer
- No external Python packages required

## How to run

Open a terminal in this folder and run:

```bash
python phishing_training.py
```

The program presents six multiple-choice questions, explains each answer,
and shows a final score. Answers are processed locally and are not saved
or transmitted.

## Topics covered

1. Suspicious emails and urgent requests
2. Sender verification
3. Fake websites and misleading HTTPS indicators
4. Social engineering and impersonation
5. Unexpected attachments
6. Reporting and responding after a suspected phishing incident

## Safety and privacy

This is a defensive awareness exercise. It does not send emails, visit
websites, collect passwords, capture credentials, or interact with real
accounts. Do not use real passwords or one-time codes in training exercises.

Follow your organization's security policy and incident-reporting process.
